# Authentication Attack

1. Review login failures by tenant, user, IP address, and user agent.
2. Confirm whether the pattern is password spraying, credential stuffing, or targeted guessing.
3. Preserve gateway and security-event logs.
4. Tighten route limits temporarily when legitimate traffic permits.
5. Lock affected accounts, revoke sessions, and require password reset.
6. Require MFA for affected privileged users.
7. Block malicious sources at the edge only after validating shared-network impact.
8. Notify security leadership when multiple tenants or privileged accounts are affected.
