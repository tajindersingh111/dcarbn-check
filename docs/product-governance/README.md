# D-carbN product governance suite

Status: controlled baseline  
Product: D-carbN Carbon Platform  
Baseline commit: `c790c5e`  
Review cadence: monthly during pilot, quarterly after production launch

This suite converts the implemented platform into a governed product baseline. It separates:

- **Implemented** — evidenced in the repository.
- **Launch dependency** — required before production use.
- **Post-launch** — deliberately outside the first commercial release.
- **Decision required** — a commercial or operational choice owned by D-carbN.

## Change control

A change to launch scope must identify the requirement, owner, acceptance criteria, security/privacy effect, migration effect, test evidence, documentation effect and release target. No feature becomes “launch required” solely because it is requested during a demonstration. Product approval belongs to the Product Owner; architecture and security approval belong to the Technical Owner; production release requires both.
