# Refresh Session Reuse Detected

1. Treat revoked-token reuse as potential session theft.
2. Confirm the automatic all-session revocation completed.
3. Lock the affected user and require password reset plus MFA verification.
4. Review recent access, role changes, exports, report generation, and tenant administration.
5. Preserve security events, IP addresses, user agents, and trace IDs.
6. Rotate signing and MFA encryption keys only when broader key compromise is suspected.
