# Elevated API Latency

1. Compare p50, p95, and p99 latency by route.
2. Inspect traces for database, Redis, serialization, and external-call spans.
3. Check connection pools, slow queries, locks, CPU, memory, and disk I/O.
4. Reduce expensive background work or pause nonessential imports.
5. Scale application capacity only after identifying the constrained resource.
6. Resolve after p95 remains below the service threshold for 30 minutes.
