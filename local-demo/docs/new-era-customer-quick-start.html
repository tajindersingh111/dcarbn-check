Scope 1, 2 & 3

New Era customer pilot
Quick-start guide

Browser-only demonstration

From prepared CSV files to a reviewable carbon report.

Use this guide during the supervised New Era pilot. The application works locally on Leonard’s demonstration laptop.

Approved data only. Use fictional or irreversibly anonymised 2025 data. Do not upload identifiable, confidential or commercially sensitive information.

  1. Open the local application

    After Leonard starts the local server, open http://127.0.0.1:8081/ on the demonstration laptop. Create the agreed pilot passphrase when prompted. Keep it private: D-carbN cannot recover it.

  2. Enter the organisation and reporting details

    Open Inventory wizard, download the organisation template, and complete the required organisation name, reporting boundary, reporting dates and confirmation fields. Set the reporting period to Calendar year 2025 (1 January–31 December 2025), save the file as CSV, then upload it.

  3. Prepare the Scope 1, Scope 2 and Scope 3 files

    Download each scope’s CSV template from the guided upload journey. Work in fresh copies and retain the supplied column headings.

    • Scope 1: direct fuel, company vehicles and refrigerants.
    • Scope 2: purchased electricity using the supported location-based method.
    • Scope 3: supported value-chain activity such as travel, transport, procurement and homeworking.

    Use a unique source record ID for every row, dates within 2025, a supported unit and method, and an evidence reference that can be traced to the source record. Do not rename, remove or add columns.

  4. Upload and validate each scope independently

    Use the matching Scope 1, Scope 2 or Scope 3 upload control. Confirm the file summary before continuing. Uploading remains local; the browser does not send the file over a network.

  5. Correct validation or duplicate errors

    The file is blocked if a row is invalid, flagged or duplicated. Read the row number and correction guidance, update the original CSV, save it again, and re-upload the complete corrected file. Common corrections include:

    • replace an invalid or out-of-period date;
    • use an accepted unit or supported method;
    • complete missing evidence or organisational metadata;
    • give duplicate rows distinct, accurate source record IDs—or remove the genuine duplicate.

  6. Submit the complete inventory to D-carbN

    Review the readiness panel. Submission is available only when the organisation file and all required scope files are valid, confirmation controls are complete, and no invalid, duplicate or flagged records remain. Select Submit to D-carbN when readiness reaches 100%.

  7. Review calculations and evidence lineage

    In Scope data, review activity quantities, units, calculated emissions and the versioned 2025 factor reference. Use the audit and evidence views to trace every result back to its uploaded source record and evidence reference. Raise any query before approval or locking.

  8. Export the approved results

    After D-carbN review and approval, open Reports. Review the report preview and export the available report and calculation outputs. The report can be locked only after the required metadata and approvals are complete.

Need help? Stop and ask Leonard before changing a template structure, choosing an unfamiliar method or accepting a result that does not look reasonable. Keep the original source and corrected CSV copies so the correction trail remains clear.
